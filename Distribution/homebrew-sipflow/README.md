# homebrew-sipflow

Вміст власного tap для встановлення SIPflow через Homebrew.

## Як опублікувати

1. Створіть на GitHub репозиторій із назвою **`homebrew-sipflow`** — префікс
   `homebrew-` обов'язковий, саме за ним `brew tap` знаходить репозиторій.
2. Скопіюйте туди теку `Casks/` із цього каталогу й запуште.
3. Створіть у репозиторії застосунку реліз `v1.0` і додайте до нього
   `dist/SIPflow-1.0.zip`, який робить `Scripts/release.sh`.

## Як встановлювати

```sh
brew tap ваш-логін/sipflow
brew install --cask sipflow
xattr -dr com.apple.quarantine /Applications/SIPflow.app
```

Третій рядок потрібен один раз після встановлення, доки застосунок підписано
самопідписаним сертифікатом. Прапорця `--no-quarantine` більше немає — Homebrew 6
його прибрала, тож зняти карантин можна лише вручну. Після отримання Developer ID
і нотаризації цей крок зникне, а `caveats` із каска можна буде прибрати.

## Оновлення версії

`Scripts/release.sh` перезаписує `Casks/sipflow.rb` з новою версією та sha256 —
файл редагувати вручну не потрібно.
