# homebrew-sipflow

A Homebrew tap for [SIPflow](https://github.com/osokolenko88/sipflow) — a SIP
softphone for macOS.

## Install

```sh
brew tap osokolenko88/sipflow
brew trust osokolenko88/sipflow
brew install --cask sipflow
xattr -dr com.apple.quarantine /Applications/SIPflow.app
```

`brew trust` is required for any third-party tap: Homebrew 6 refuses to load
casks from taps you have not explicitly trusted. Read the cask first if you
like — it is fifteen lines.

The last line is needed once. SIPflow is signed with a self-signed certificate
and is not notarized, so Gatekeeper refuses a downloaded archive. Homebrew 6
removed the `--no-quarantine` flag, so the attribute has to be cleared by hand.

Building from source avoids this entirely — a locally built app is never
quarantined. See the
[project README](https://github.com/osokolenko88/sipflow#installation).

## Requirements

macOS 15 or newer, Apple Silicon.

## Updating the cask

The cask is generated by `Scripts/release.sh` in the main repository: it builds
the app, packages it, computes the checksum and rewrites `Casks/sipflow.rb`.
Copy the result here rather than editing by hand — every build produces a new
signature and therefore a new sha256.
